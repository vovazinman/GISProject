✅ Architecture Principles

🎯 Separation of Concerns

Each layer has a single responsibility. Presentation handles UI, Application orchestrates business logic, Domain contains core rules, Infrastructure manages data.

⬇️ Dependency Flow

Dependencies flow inward: Presentation → Application → Domain ← Infrastructure. Domain is independent and reusable across different UIs and databases.

🔄 Data Flow

Horizontal flow: User → API → Services → Domain Logic → Cache Check → Database → Search Index → Real-time Broadcast → UI Update (complete cycle).
